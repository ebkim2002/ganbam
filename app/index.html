☾간밤벙주 정산
기기 내 정산 · 로그인 없음

벙주가 입력하고 결과를 카톡에 직접 공지하세요. 기본 입력은 이 탭에서만 유지됩니다. ‘이 기기에 초안 저장’을 눌러야 브라우저에 보관되며 서버에는 저장하지 않습니다.

간밤을 홈 화면에

휴대폰에서는 HTTPS로 제공되는 앱 주소를 연 뒤 설치할 수 있습니다. 현재 PC의 로컬 주소는 휴대폰 설치가 완료된 상태가 아닙니다.

iPhone Safari
공유 → 홈 화면에 추가

Android Chrome / PC Edge
브라우저 메뉴 → 앱 설치 또는 홈 화면에 추가

사용 순서

모임·참석자와 차수별 음식·술값을 입력합니다. 이름 옆에서 음주 여부를 선택한 뒤 결과를 확인하세요.

‘이미지 저장’ 또는 ‘공지문 복사’ 후 카카오톡 단톡방에 직접 올립니다. 카톡 자동 전송은 하지 않습니다.

초안은 기본적으로 이 탭의 메모리에만 있습니다. ‘이 기기에 초안 저장’을 누른 경우에만 브라우저에 보관합니다. 추가 전 이름도 초안에 포함됩니다. 새 버전 적용은 동의 후 초안을 저장하고 다시 불러옵니다. 브라우저 데이터 삭제·기기 변경 시에는 복원되지 않습니다. 원본 계정의 서버 저장과는 별개입니다.
